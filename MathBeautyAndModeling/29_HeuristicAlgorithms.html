第 29 章 启发式算法: 在复杂解空间中搜索较优方案

一辆配送车要访问若干社区服务点, 最后返回服务站. 先别急着选择算法, 拿四个点算一条路线: 每个点有没有访问, 回程有没有计入, 总长度是多少? 搜索过程中每产生一条新路线, 都要回到这几个问题.

本章先用四点小例练习一次评价, 一次邻域变化与一次接受判断, 再在同一组十点数据上运行最近邻, 模拟退火, 遗传与蚁群算法. 小例用于手算操作, 十点实例用于完整试验, 两者的长度不混在同一张比较表中.

29.1 先算一条闭合路线: 回程也是目标的一部分

地点 0, 1, 2, 3 的教学坐标依次为 \((0,0)\), \((3,0)\), \((3,4)\), \((0,4)\), 单位为 km. 两点间使用直线距离, 暂不考虑道路绕行. 路线按 \(0\to1\to2\to3\to0\) 访问.

距离(km) 3 4 3 4

前三段合计 10, 加回程才是完整长度 14. 程序只保存编号 [0,1,2,3], 最后一条边由循环接回首项, 不再把 0 重复存进路线列表.

只在这几条路线中取最小值, 得到的是已列候选的最好值. 要说它是整个问题的最优值, 还需要完整搜索或有效的最优性证据. 后面的十点主试验会另设精确基准.

Python · tsp_data.py

MATLAB · tspData.m

令访问顺序为 \(\boldsymbol\pi=(\pi_0,\ldots,\pi_{n-1})^{\mathsf T}\), 定义闭合端点 \(\pi_n=\pi_0\). 完整模型如下, 排列条件保证每个地点恰好一次:

\[ \begin{gathered} \min_{\boldsymbol\pi}\ L(\boldsymbol\pi) =\sum\limits_{r=0}^{n-1}d_{\pi_r,\pi_{r+1}} \\[4pt] \left\{\begin{aligned} \pi_0&=0,\\ \pi_n&=\pi_0,\\ \pi_r&\in\{0,1,\ldots,n-1\},\quad r=0,\ldots,n-1,\\ \pi_r&\ne\pi_s,\quad 0\leqslant r<s\leqslant n-1. \end{aligned}\right. \end{gathered} \]

模型是旅行商问题, 简称 TSP. 这里的历史名称对应闭合访问模型, 同样可用于配送和巡检. 若道路有向, 有不可达边或时间窗, 要重新说明约束, 不能继续无条件使用本章对称距离程序. [3]

29.4 产生邻近方案: 反向一个片段, 保持访问编号不变

有了当前路线, 可以改变其中一部分得到候选. 先用六个编号演示位置操作: 将 [0,1,2,3,4,5] 中编号 1, 2, 3 所在的连续片段反向, 得到 [0,3,2,1,4,5].

Python · step04_reverse_move.py

MATLAB · step04_reverse_move.m

Python 切片 [1:4] 表示位置 1, 2, 3, 右端位置 4 不取. MATLAB 对应位置 2 至 4. 这里改变的是访问位置, 不在编号本身上做加减运算.

反向后编号不增不减, 所以保持排列可行, 但路线是否更短必须重新计算. 候选用新列表保存, 原路线保留供后续接受或拒绝. 这个六编号例子只说明算子, 没有给它另算一个能与十点结果混比的长度.

交换位置, 反向片段, 搬移片段都可设计成邻域. 邻域决定一步能走向哪里, 接受规则决定是否真的走过去, 两项任务应分别讲清.

29.5 模拟退火: 候选变长时, 怎样决定是否接受

29.5.1 先做一次数值判断

当前路线长 360 km, 候选长 370 km, 长度增加量 \(\Delta=10\). 若只接受不变差的候选, 这一步就会被拒绝. 模拟退火在正温度 \(T\) 下, 允许按一定概率接受较差候选, 给离开局部较好区域保留机会. [1]

本章采用的接受概率为

\[ P_{\mathrm{accept}}=\begin{cases} 1,&\Delta\leqslant0,\\ \mathrm{e}^{-\Delta/T},&\Delta>0. \end{cases} \]

当 \(T=20\), 概率约为 0.606531; 当 \(T=1\), 概率约为 0.0000454. 取一次 \([0,1)\) 上的均匀随机数 \(u\), 只有 \(u<P_{\mathrm{accept}}\) 才接受. 为便于逐项核对, 下列程序固定试用 \(u=0.2\) 与 \(u=0.8\).

Python · step05_acceptance.py

MATLAB · step05_acceptance.m

在温度 20 时, 增长 10 的候选会被 \(u=0.2\) 接受, 被 \(u=0.8\) 拒绝. 更短或等长候选的接受概率为 1. 高温与低温改变的是接受倾向, 并不是保证一定找到最优的开关.

\(\Delta/T\) 应无量纲, 温度数值须匹配目标值尺度. 如果把长度单位由 km 改为 m, 增量扩大 1000 倍, 保持相同接受倾向时温度也要按相同比例调整. 温度是算法参数, 不是物理摄氏度.

29.6 遗传算法的交叉: 编号不能重复或遗漏

遗传算法同时维护多条候选路线, 组成种群. 一条路线为一个个体. 先不讨论整代搜索, 只看两条父代怎样生成合法后代.

父代为 [0,1,2,3,4,5] 与 [0,3,5,1,4,2]. 从父代一取出片段 [1,2,3], 在父代二中读取这些编号的相对顺序, 得到 [3,1,2].

Python · step07_feasible_crossover.py

MATLAB · step07_feasible_crossover.m

第一条后代把父代一未取出的部分 [0,4,5] 与 [3,1,2] 拼起来. 第二条从父代二删去同一组编号, 将剩余 [0,5,4] 与原片段 [1,2,3] 拼起来.

取出集合与剩余集合不重叠, 合起来仍覆盖全部编号, 所以后代保持排列. 起点 0 不在片段中, 仍位于首项. 这是一种片段重排设计, 不等同于把两条字符串任意截断后拼接, 也不声称比其他排列交叉更优.

交叉后的路线仍需评价. 六编号例子只展示算子可行性, 十点试验仍使用原固定数据. 交叉与片段反向变异的完整随机实现见进阶阅读 F.5.4.

29.7 精英保留: 父代最好路线怎样继续留下

交叉和变异不保证每条后代都变好. 一种明确的生存规则是: 把未改动父代与新后代一起按闭合长度排序, 再保留规定数量的最短路线.

下面用四点路线, 父代长度 14 与 16, 后代长度 18 与 14, 从四条中保留两条. 反向环路可能同长, 这里允许它们作为不同排列同时出现.

Python · step08_elite_selection.py

MATLAB · step08_elite_selection.m

保留的最好长度不会比父代最好值更大, 因为旧的最好父代仍在候选池中. 如果先把唯一的最好父代原地变异而没有备份, 就没有这个理由. 精英保留保证的是已找到的最好值不丢失, 不是保证下一代一定找到更优值.

本章完整实现还允许自配对与重复个体. 它便于教学, 也可能减少多样性. 若变异函数返回新列表, 必须把返回值写回后代集合, 仅给循环临时变量重新赋值不会替换原集合中的路线.

图 29-4 六编号的交叉与十点遗传试验的历史最好曲线. 两部分分别检查可行重组与实际搜索结果, 不把六编号算子当作完整十点试验.

完整十点遗传算法使用 10 条保留个体, 初始先评价 100 条随机路线, 每代有序配对最多产生 200 条后代. 原示范交叉概率为 1, 变异概率 0.1, 共 10 代, 完整评价数为 \(100+10\times200=2100\). 排序, 交叉与变异还有额外工作, 不能只数代数.

29.8 蚁群的下一站: 先算权重, 再归一化为概率

29.8.1 一次选择可以手算

在四点例子中, 当前位于 0, 未访问点 1, 2, 3 的距离为 3, 5, 4. 若三条边的信息素都为 0.2, 距离启发信息取倒数, 且两个指数都为 1, 未归一化权重为 \(0.2/3\), \(0.2/5\), \(0.2/4\).

权重不是概率, 先除以权重总和. 结果为

\[ (P_1,P_2,P_3)^{\mathsf T} =\left(\frac{20}{47},\frac{12}{47},\frac{15}{47}\right)^{\mathsf T}. \]

Python · step09_transition_probabilities.py

MATLAB · step09_transition_probabilities.m

概率之和为 1. 最近的点 1 概率最高, 但并不是每次都选它. 为了看清累积区间, 程序把一次均匀随机数的取值固定成 0.5: 它落入点 2 对应的区间, 因而这次选择距离为 5 的点.

确定下一站后, 将它从未访问集合中删除, 再从新位置重新计算概率. 这保证逐步构造的路线不会重复地点, 但最后仍须接回起点.

29.8.2 一般转移规则

记信息素为 \(\tau_{ij}\), 距离启发信息为 \(\eta_{ij}=1/d_{ij}\), 尚未访问集合为 \(J_i\). 则

\[ P_{ij}=\begin{cases} \dfrac{\tau_{ij}^{\alpha}\eta_{ij}^{\beta}} {\sum\limits_{u\in J_i}\tau_{iu}^{\alpha}\eta_{iu}^{\beta}},&j\in J_i,\\ 0,&j\notin J_i. \end{cases} \]

\(\alpha\) 和 \(\beta\) 调节两类信息的作用. 信息素相同时, 距离仍影响概率. 蚁群借鉴群体信息交流形成搜索方法, 不逐细节模拟真实蚂蚁, 也不是每次确定性选择信息素最多的边. [2]

29.9 完成一条路线后, 怎样更新信息素

29.9.1 先算一只蚂蚁的一轮

四点闭合路线 \(0\to1\to2\to3\to0\) 长 14. 取强化尺度 \(Q=10\), 旧信息素非对角元素均为 0.2, 旧值保留率为 0.4. 对这条完整路线经过的每条边, 都加入同样的 \(Q/L=10/14\).

Python · step10_pheromone_update.py

MATLAB · step10_pheromone_update.m

使用边 \(0\leftrightarrow1\) 的新信息素约为 \(0.4\times0.2+10/14=0.794286\). 未使用边 \(0\leftrightarrow2\) 没有新增量, 只留下 \(0.4\times0.2=0.08\). 距离对称时同时更新两个方向, 对角线保持 0.

图 29-5 四点例子的一次转移概率和一只蚂蚁完成后的信息素. 左图是下一站的概率, 右图是完整路线评价后的新矩阵, 两种对象不能混用.

29.9.2 保留率, 挥发率与强化规则要说清

保留率为 0.4, 意味着旧值挥发掉 0.6. 记挥发率为 \(\rho\), 多只蚂蚁完成后可写为

\[ \tau_{ij}^{\mathrm{new}}=(1-\rho)\tau_{ij}^{\mathrm{old}} +\sum\limits_{a=1}^{m}\Delta\tau_{ij}^{(a)}, \]

\[ \Delta\tau_{ij}^{(a)}=\begin{cases} Q/L_a,&\text{蚂蚁 }a\text{ 的环路使用边 }\{i,j\},\\ 0,&\text{否则}. \end{cases} \]

这里按整条环路长度强化, 同一只蚂蚁在所用各边增加相同数值. 如果改为 \(Q/d_{ij}\), 就变成按单边长度强化的另一规则. 完整程序用 deposit='tour' 表示主例整路强化, 用 deposit='edge' 保留局部强化变体, 二者的结果和公式应分开.

主例每代所有蚂蚁都使用更新前的同一矩阵, 全部完成后统一挥发并加上本代增量. 这与边构造边立即更新是不同的时序. 完整双语言程序见进阶阅读 F.6.4.

29.10 完整运行以后, 怎样判断结果质量

29.10.1 用两种精确算法建立十点小实例的基准

固定起点后有 \(9!=362880\) 个访问排列. 本例距离对称, 一条环路反向后长度相同, 因而只需评价 \(9!/2=181440\) 条去除反向重复的环路. 这减少重复方向, 没有消除阶乘增长.

完整枚举得到最短长度约 342.922073 km. 一条达到该值的路线为

\[ 0\to4\to5\to6\to3\to9\to1\to7\to2\to8\to0. \]

另用子集动态规划独立核对, 2304 个集合/终点状态得到同样长度. 完整枚举程序见进阶阅读 F.2.4, 子集递推与代码见 ExactTSPBaseline.md, 它也承接上一章的状态设计. 距离仍以浮点计算, 六位小数不是严格区间证书.

TSP 优化是 NP-hard 问题. 规模变大时, 可以根据结构和资源使用或组合精确方法, 近似方法与启发式方法, 不应说"大问题只能用启发式". 最优值未知时也可利用有效界与已知好解评价, 但不能把已知最好值自动称作已证明最优值.

29.10.5 检查结果与继续阅读

  1. 先回代每个地点恰好一次与回程边, 再看长度是否更短.
  2. 检查新算子保持排列, 是否改动了需要保留的父代或历史最好路线.
  3. 区分当前值和历史最好值, 检查最终路线与记录长度一致.
  4. 对随机方法说明种子, 参数, 停止条件与实际评价预算.
  5. 区分找到一个好解, 达到本例精确基准, 与获得一般最优保证.
  6. 检查距离, 通行, 容量和服务要求是否与实际任务相符.

启发式是利用问题结构或搜索规则寻找较好可行解的方法. 模拟退火, 遗传和蚁群属于可迁移到多类问题的元启发式框架, 仍需为具体问题设计表示, 算子和约束处理. 有限预算的结果通常不带一般全局最优保证. 曲线平台是运行现象, 不能当作证明.

29.10.6 分步练习

  1. 四点闭合路线为何为 14 而不是 10? 若程序把终点 0 又存入排列, 可行性检查为什么需要重新考虑?
  2. [0,1,2] 经过的路段可能较少, 为什么不能与四点完整路线一起按短者优先排名?
  3. 当前在 0, 未访问点距离为 3, 5, 4, 最近邻先选谁? 下一步为何要重新从新位置计算?
  4. 将六编号路线位置 1 至 3 反向, 分别写出 Python 切片和 MATLAB 位置, 核对编号是否仍完整.
  5. 当前长 360, 候选长 370, 温度 20, 若 u=0.2 或 0.8, 是否接受? 长度换为 m 后怎样保持同一概率?
  6. 当前长度依次为 18, 14, 16, 18, 历史最好曲线怎样记录? 最后应返回哪份路线?
  7. 从两个父代取出编号 1, 2, 3, 为什么本章重组后仍是排列? 普通拼接可能发生什么?
  8. 父代最短长度 14, 后代都为 16 或 18. 父代与后代共同选最短者, 是否会丢掉 14? 若先改坏父代又会怎样?
  9. 四点例子的三种转移概率是多少? 固定 u=0.5 为什么会选到距离 5 的点?
  10. 一只蚂蚁走完长度 14 的环路, Q=10, 保留率 0.4, 旧值 0.2. 求使用边与未使用边的新值, 并说明 20 次到达最优为何仍不是一般保证.
