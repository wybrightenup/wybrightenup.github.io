第10章 主成分分析: 换个方向, 看见数据的主要变化

一张数据表可能记录许多变量, 却没有同样多种相互区别的变化. 身高与臂长往往一起变化, 多项投入费用也可能随年份共同升高. 能否用少数几个坐标概括这些差异, 同时知道压缩后舍去了多少变化?

主成分分析(Principal Component Analysis, PCA)通过重新组合变量回答这个问题. 它寻找样本变化最大的方向, 再保留其中几个. 这里的"信息保留"有明确含义: 保留所选尺度下的方差, 而不是保留数据的所有用途.

本章先用五个点完成一次投影与重建, 再用棉花投入数据走通标准化, 选维数, 计算得分和检查误差的全过程. 最后分析只给定相关矩阵的人体尺寸问题, 说明不同输入能回答哪些问题. 三个案例均给出完整的 Python 与 MATLAB 程序.

10.1 先做一次: 两个坐标如何变成一个

10.1.1 沿着数据伸展的方向看

考虑五个点:

\[ (1,2),\ (2,4),\ (3,6),\ (4,8),\ (5,10). \]

它们都位于直线 \(y=2x\) 上. 虽然每个点有两个坐标, 但知道其中一个, 就能确定另一个. 这组数据实际上只沿一个方向变化.

先把平均位置 \((3,6)\) 移到原点. 选取沿直线方向的单位向量和垂直方向的单位向量:

\[ a_1=\frac1{\sqrt5}(1,2)^{\mathsf T}, \qquad a_2=\frac1{\sqrt5}(-2,1)^{\mathsf T}. \]

新坐标就是中心化后的点在这两个方向上的投影.

原坐标 中心化坐标 第一新坐标 第二新坐标
\((1,2)\) \((-2,-4)\) \(-2\sqrt5\) 0
\((2,4)\) \((-1,-2)\) \(-\sqrt5\) 0
\((3,6)\) \((0,0)\) 0 0
\((4,8)\) \((1,2)\) \(\sqrt5\) 0
\((5,10)\) \((2,4)\) \(2\sqrt5\) 0

第二新坐标对所有点都是0. 删去它并不丢失这五个点的变化, 第一新坐标就足够重建原数据.

本例两个坐标采用同一单位, 只做中心化, 不做标准差缩放. 若改为每列标准化, 投影方向也会相应改变; 讨论方向时必须先说明数据尺度.

10.1.2 用程序验证投影与重建

程序只做四件事: 将平均位置移到原点, 求最大特征值对应的单位方向, 计算投影坐标, 再从一个坐标重建两个坐标. Python 的一维数组 a 表示方向的各个分量; 数学上方向仍写为列向量.

10.2.2 为什么本例先标准化

五项投入的波动量级不同. 直接按原数值计算, 方差较大的费用项会更强地影响主方向. 本例希望五项指标都以单位方差参与比较, 因此使用每列的样本均值与样本标准差:

\[ \bar x_j=\frac1n\sum\limits_{i=1}^{n}x_{ij},\qquad s_j=\sqrt{\frac1{n-1}\sum\limits_{i=1}^{n}(x_{ij}-\bar x_j)^2},\qquad z_{ij}=\frac{x_{ij}-\bar x_j}{s_j}. \]

标准化不是所有PCA的必需步骤. 如果原单位下的波动差异本来就具有分析意义, 可以只中心化. 两种处理对应不同的方差尺度, 因而可能得到不同方向.

将标准化后的18行, 5列数据记为 \(Z\), 其样本协方差矩阵就是原变量的样本相关系数矩阵:

\[ R=\frac1{17}Z^{\mathsf T}Z. \]

这里使用样本标准差, 分母为 \(n-1\). Python 的 std(ddof=1) 与 MATLAB 的 std(X,0,1) 使用同一口径. 缺失值, 无限值和常数列应先处理; 以下程序针对表中完整且各列非常数的数据.

10.2.3 程序按三项任务展开

第一项任务生成 \(Z\) 和 \(R\). 第二项任务把特征值从大到小排序, 同时调整特征向量的列. 第三项任务保留方向, 计算得分, 相关载荷与重建. 三项任务在两种语言的程序中一一对应, 无需另外编写自定义函数.

10.2.5 系数, 载荷和得分分别回答什么

程序输出的 W, loadings 和 score 不能互换.

输出 本例维数 回答的问题
组合系数 \(W\) \(5\times2\) 怎样将五项标准化投入组合成两个坐标?
相关载荷 \(L\) \(5\times2\) 各原变量与各主成分的样本相关性多强?
得分 \(F\) \(18\times2\) 各年份在两个新方向上的坐标是多少?

记 \(a_k=(a_{1k},\ldots,a_{pk})^{\mathsf T}\), \(W=(a_1,\ldots,a_k)\), 则

\[ F=ZW,\qquad \ell_{jk}=\sqrt{\lambda_k}a_{jk}. \]

后一公式适用于标准化变量和正方差主成分. 例如农药费在第二方向的组合系数约为0.922424, 对应相关载荷约为0.821250. 系数用于计算得分, 相关载荷用于描述相关性. 有些软件把组合系数也称为载荷, 阅读输出时应先核对定义.

得分为负表示样本位于所选轴的负方向, 不表示费用为负或表现较差. 将一个方向整列反号, 相应得分也会整列反号, 解释率, 投影距离和重建均不变. 因此不能把PCA得分自动当作优劣排名.

10.2.6 用重建检查压缩损失

保留两个坐标后, 标准化数据的近似重建为

\[ \widehat Z=FW^{\mathsf T}=ZWW^{\mathsf T},\qquad \widehat x_{ij}=\bar x_j+s_j\widehat z_{ij}. \]

本例标准化数据的平方重建误差约为1.917586, 它占总平方离差85的约2.2560%. 这里85来自 \((18-1)\times5\). 这与被舍弃方差的比例相同, 是检查计算是否一致的一种方法.

程序还按变量输出原单位下的重建均方根误差. 不同变量的误差应分别看, 不能把标准化误差误写成费用误差, 也不能把较小的总误差理解为每个年份, 每项费用都重建得同样好.

图10-3　逐变量检查重建误差

左图比较保留一个和两个主成分时各变量的标准化重建均方根误差. 右图比较原始值与保留两个成分后的重建值, 每个坐标先按该变量的均值和标准差换算. 对角线表示重建完全相同. 原始尺度的误差应回到程序输出逐项查看.

10.2.7 新样本沿用同一套坐标

对新记录, 使用已有模型的均值, 标准差和方向, 再计算 ((x_new-mean)/scale) @ W 或 MATLAB 的 ((x_new-mu)./scale)*W. 程序用第一条已有记录演示这个操作, 因而所得结果应等于得分表的第一行; 这只是变换核对, 不是独立样本的验证.

如果日后要预测单产, 应先按任务划分训练与验证数据, 再仅用训练数据估计均值, 标准差与方向. 验证数据沿用这套变换. 对连续年份通常还应保持时间先后, 防止未来信息进入训练过程.

本例各年份之间可能存在趋势, 投入费用还可能受到价格与技术变化影响. PCA不需要用独立同分布假设才能完成这里的矩阵计算, 但若要进一步推断, 预测或推广, 就必须检查这些数据结构. 不能据高解释率推断投入的因果作用.

10.4 为什么这些方向最合适

10.4.1 最大方差的标准模型

把中心化或标准化后的数据协方差矩阵统一记为 \(C=Z^{\mathsf T}Z/(n-1)\). 第一方向 \(a=(a_1,\ldots,a_p)^{\mathsf T}\) 由下列模型确定:

\[ \begin{aligned} \max_{a}\quad &a^{\mathsf T}Ca,\\ \text{s.t.}\quad &\left\{\begin{aligned} a^{\mathsf T}a&=1. \end{aligned}\right. \end{aligned} \]

单位长度约束避免任意放大方向来增加投影方差. 对第 \(r\) 个方向, 还要求与已选方向正交:

\[ \begin{aligned} \max_{a}\quad &a^{\mathsf T}Ca,\\ \text{s.t.}\quad &\left\{\begin{aligned} a^{\mathsf T}a&=1,\\ a^{\mathsf T}a_j&=0,\quad j=1,\ldots,r-1. \end{aligned}\right. \end{aligned} \]

对称矩阵的特征值按 \(\lambda_1\geqslant\cdots\geqslant\lambda_p\geqslant0\) 排列. 将任意单位方向写成其正交单位特征向量的组合, 有

\[ a=\sum\limits_{j=1}^{p}c_ja_j,\qquad \sum\limits_{j=1}^{p}c_j^2=1,\qquad a^{\mathsf T}Ca=\sum\limits_{j=1}^{p}\lambda_jc_j^2\leqslant\lambda_1. \]

所以第一方向取最大特征值对应的单位特征向量. 依次在剩余正交空间内求解, 就得到后续方向. 特征值等于对应得分的样本方差, 解释率为

\[ \alpha_j=\frac{\lambda_j}{\sum\limits_{r=1}^{p}\lambda_r},\qquad G_k=\sum\limits_{j=1}^{k}\alpha_j. \]

10.4.2 方差保留与重建误差是同一件事的两面

在给定维数的正交线性投影中, 保留前 \(k\) 个主方向使平方重建误差最小, 并且

\[ \|Z-\widehat Z\|_{\mathrm F}^2 =(n-1)\sum\limits_{j=k+1}^{p}\lambda_j. \]

式中 \(\|A\|_{\mathrm F}^2\) 表示矩阵各元素平方的总和. 它说明解释率与整体重建损失对应, 但这个结论只针对指定的尺度与平方损失, 不保证分类, 回归或异常检测效果最好.

中心化数据的秩不超过 \(\min(n-1,p)\). 总方差为0时, 所有样本没有变化, 解释率无定义. 标准化时存在常数列, 则标准差为0, 不能直接相除.

10.4.3 不相关与独立有何不同

不同方向的得分满足

\[ \operatorname{Cov}_{\text{样本}}(Za_r,Za_s) =a_r^{\mathsf T}Ca_s=0,\qquad r\ne s. \]

这里得到的是所用样本中的不相关, 不是一般意义上的统计独立, 也不保证未来样本仍有恰好为0的协方差. 若随机变量 \(U\) 在 \([-1,1]\) 上均匀分布, \(V=U^2\), 对称性给出 \(\operatorname{Cov}(U,V)=0\), 但知道 \(U\) 就能确定 \(V\).

图10-5　相同特征值与不相关但依赖

左图24个点均匀分布在单位圆上, 两个特征值相同. 任意正交轴组都可作为主方向, 任一方向均保留50%的方差. 右图是 \(V=U^2\), 说明线性相关性为0也可能存在确定性的非线性关系.

当特征值重复时, 对应子空间中的轴不唯一; 特征值接近时, 小扰动也可能使轴明显转动. 这时应更多关注保留的子空间及重建, 不宜给每根轴赋予过于确定的含义.

10.5 由案例整理出一条可复用的分析路线

实际问题先确定要压缩什么, 再决定用什么尺度衡量差异. 有逐行样本数据时, 可以计算方向, 得分和重建; 只有相关或协方差矩阵时, 只能得到其支持的方向与方差结构. 这一区别应在程序之前说明.

环节 应做的判断 应检查的结果
明确输入 哪些是分析指标, 哪些是标识或预测目标? 行列含义与输入范围
选择尺度 原单位下的方差差异是否有意义? 均值, 标准差与常数列
计算方向 特征值与方向是否同步排序? 正交性, 非负特征值与总方差
选择维数 解释率要求与具体任务是什么? 累计解释率, 重建及任务表现
解读输出 讨论的是系数, 载荷还是得分? 正负结构与专业含义
使用新样本 是否沿用已有变换? 训练过程与验证过程的边界

PCA对异常样本和尺度敏感. 少数主成分未保留足够方差时, 算法仍可计算, 只是压缩收益有限. 大方差可能来自测量误差或共同趋势, 小方差也可能包含重要预测信号. 降维是否值得使用, 应回到具体任务验证.

实际算法库常用奇异值分解, 将 \(Z=U\Sigma V^{\mathsf T}\) 分解后, 取 \(V\) 的前几列为主方向, 由 \(\lambda_j=\sigma_j^2/(n-1)\) 得到特征值. 它与本章特征分解给出相同的主子空间, 同时避免显式构造协方差矩阵带来的条件数平方问题. 这里直接分解小型矩阵, 是为了看清各步之间的关系.

Python 的 sklearn.decomposition.PCA 和 MATLAB 的 pca 默认中心化数据, 不自动按本章口径逐列标准化. 使用库函数时仍需主动决定尺度. MATLAB 的 pca 需要 Statistics and Machine Learning Toolbox; 本章三个完整算例均使用基础 MATLAB 的 eig, 不依赖该工具箱.

10.6 练习: 让判断与计算相互验证

  1. 将五点算例的第二坐标扩大10倍. 比较仅中心化与逐列标准化得到的方向, 解释单位选择为何会影响结果.
  2. 将棉花投入案例的阈值分别改为80%, 90%和95%, 记录成分数, 解释率及重建误差.
  3. 计算棉花投入得分的样本协方差矩阵, 检查对角元素与特征值是否对应, 非对角元素是否在数值误差范围内为0.
  4. 将一个方向及其得分都反号, 比较重建. 为什么原始得分不能直接提供稳定的优劣排序?
  5. 人体尺寸案例达到80%, 90%和95%分别需要几个成分? 如果坚持二维展示, 应怎样说明信息损失?
  6. 用前12年的棉花投入估计均值, 标准差与方向, 再变换后6年. 解释它与对全部年份重新做PCA的区别. 这个操作本身是否已经验证了单产预测能力?
  7. 对棉花投入分别做仅中心化与标准化PCA, 比较方向与重建. 为什么两种尺度下的平方误差不能直接比较大小来决定哪一种更好?
