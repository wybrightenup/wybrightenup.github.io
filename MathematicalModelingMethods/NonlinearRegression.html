第 9 章 曲线回归与非线性拟合: 先看模型, 再选算法

前面已经把多个解释变量放进同一个回归模型. 如果散点呈现曲线, 是否一定要换成迭代求解? 如果对数据取对数后能拟合直线, 还原后是否就等于在原尺度上完成了最小二乘?

本章从钢包容积增大量的数据出发, 在同一候选函数下比较两种拟合目标. 随后用距离与时间说明多项式仍可线性求解, 再用商品需求说明平方项的解释与区间类型. 三个案例分别回答误差尺度, 参数线性与预测对象的问题.

9.1 先看数据, 再确定候选曲线

9.1.1 一条缺失记录不能当成零

第 1 次使用的响应缺失, 用 nan 或 NaN 表示. 只用 \(x=2,\ldots,16\) 的 15 组有效观测拟合, 保留缺失标记, 不填成零. 零是一个具体观测值, 还会使后面的对数变换不可用, 与缺失不是一回事.

9.1.2 图像弯曲与参数非线性分开判断

试用候选均值函数

\[ f(x;a,b)=a\mathrm e^{b/x},\qquad x>0. \]

当 \(a>0,b<0\) 时, 它随 \(x\) 增大而上升, 并趋近 \(a\). 这与散点后期增长趋缓的形状相容, 但图形并不能证明它是唯一正确的模型. 该曲线在 \(x=-b/2\) 处有拐点, 样本可能只覆盖拐点后的一段.

未知参数 \(b\) 位于指数中, 所以它对参数非线性. 相比之下, \(\beta_0+\beta_1x+\beta_2x^2\) 虽是一条抛物线, 对三个未知系数仍然线性. 判断求解路线时, 应看参数怎样进入方程, 而不是只看图是否弯曲.

9.2 同一条候选曲线, 两个不同的拟合目标

9.2.1 取对数后, 拟合的是哪一种差异

当观测 \(x_i,y_i\) 均为正时, 令 \(A=\ln a\), 得到

\[ \ln y=A+\frac b x. \]

把 \(1/x\) 作为解释变量, \(\ln y\) 作为响应, 求解无约束最小二乘:

\[ \min_{A,b}\ Q_{\log}(A,b) =\sum\limits_{i=1}^{15}\left(\ln y_i-A-\frac b{x_i}\right)^2. \]

估计得到 \(\widehat A=2.4577846855\), \(\widehat b=-1.1106713598\). 还原 \(\widehat a=\mathrm e^{\widehat A}\) 后,

\[ \widehat y_{\log}=11.6789104013\mathrm e^{-1.1106713598/x}. \]

还原曲线的原尺度训练 SSE 为 0.891281, RMSE 为 0.243760. 这些是还原后另算的拟合指标, 参数本身通过对数尺度误差求得. 这里的拐点约为 0.5553, 不在 \([2,16]\) 的样本范围内, 所以数据只表现为拐点后的增长趋缓.

9.2.2 直接拟合原尺度时, 把约束写进模型

如果主要比较容积增大量的原尺度偏差, 可以直接求解

\[ \begin{gathered} \min_{a,b}\quad Q_y(a,b)=\sum\limits_{i=1}^{15}\left(y_i-a\mathrm e^{b/x_i}\right)^2,\\[3pt] \text{s.t.}\quad \left\{\begin{aligned} a&\geqslant0,\\ b&\leqslant0. \end{aligned}\right. \end{gathered} \]

第一行是目标函数, 下面给出本例选用的参数约束. \(a=0\) 或 \(b=0\) 属于允许的边界情形; 得到的内部估计满足 \(a>0,b<0\). 这些限制依据本例希望描述的非负, 增长形状设定, 不是所有倒指数数据都适用的通用要求.

直接拟合需要初值与迭代. 本例从对数线性化结果开始, 得到

\[ \widehat y_{\mathrm{NLS}}=11.6036675\mathrm e^{-1.0641295/x}. \]

拟合路线 \(a\) \(b\) 原尺度训练 SSE 原尺度训练 RMSE
对数线性化后还原 11.6789104 -1.1106714 0.891281 0.243760
原尺度非线性最小二乘 11.6036675 -1.0641295 0.862665 0.239814

图 9-2 同一钢包数据的两种拟合. 左图为还原曲线与直接拟合曲线, 右图为原尺度残差. 曲线接近不表示两种最小二乘目标相同.

直接拟合的原尺度 SSE 较小, 与它所最小化的目标一致. 不能由此认定它在所有新数据上更准确. 如果观测误差的绝对波动大致恒定, 原尺度目标更符合这一设定; 如果误差与响应量级近似成比例, 对数尺度模型可能更合适, 仍需结合测量过程与残差判断.

响应取对数并非单纯换一种代数写法. 若模型为 \(\ln Y=A+b/x+\eta\), 且 \(\eta\mid x\sim N(0,\tau^2)\), 则

\[ \operatorname{median}(Y\mid x)=\mathrm e^{A+b/x},\qquad \mathbb E(Y\mid x)=\mathrm e^{A+b/x+\tau^2/2}. \]

直接取指数对应条件中位数的代入估计, 一般不是原尺度条件均值的估计. 这也是比较两条曲线时应先交代误差模型的原因.

9.3 把非线性求解与近似区间连起来

9.3.1 程序里的函数, 初值和边界分别是什么

Python 的 curve_fit 接收函数 curve(x,a,b), 15 组有效数据, 初值 p0 与 bounds[1]. 函数内部按当前参数给出所有预测, 求解器反复调整参数以减小残差平方和. beta 按 \((a,b)\) 的顺序返回, 不能把它与线性化的 \((A,b)\) 混用.

MATLAB 程序使用基础函数 fminsearch, 它本身是无约束局部优化工具[2]. 为搜索约束内部, 设置 \(a=\mathrm e^u,b=-\mathrm e^v\), 对 \(u,v\) 迭代, 然后分别比较 \(a=0\) 和 \(b=0\) 的边界目标. 参数变换不表示求解器直接支持箱约束, 也不能替代一般约束问题的全局最优分析. 本例内部解的目标值小于两类边界值.

停止条件满足只说明算法按设定停止. 还应检查参数, 残差, 雅可比的秩及协方差的数值状况, 并用几个合理初值核查结果是否一致. 即便多次得到近似相同结果, 也不能自动把局部算法的输出称为全局最优.

9.3.2 非线性区间为什么只能作近似解释

在 \(x_0=10\) 处, 点预测约为 10.432316. 以样本拟合函数对参数的雅可比矩阵 \(J\) 和新位置梯度

\[ g=\left(\mathrm e^{b/x_0},\frac{a\mathrm e^{b/x_0}}{x_0}\right)^{\mathsf T} \]

在误差独立同方差, 条件均值为零并采用正态误差模型的条件下作局部线性近似, 得到

\[ \widehat{\operatorname{Cov}}(\widehat\theta)\approx s_e^2(J^{\mathsf T}J)^{-1},\qquad \widehat{\operatorname{Var}}(\widehat y_0)\approx g^{\mathsf T}\widehat{\operatorname{Cov}}(\widehat\theta)g, \]

其中 \(\widehat\theta=(\widehat a,\widehat b)^{\mathsf T}\), \(s_e^2=SSE/(15-2)\). 新观测的方差近似还需加上 \(s_e^2\). 本例结果为:

对象 近似 95% 区间
x=10 时的平均响应 \([10.271252,10.593379]\)
同一条件下新的独立响应 \([9.852962,11.011670]\)

这些区间依赖模型形式, 误差条件和局部近似质量. 它们不是设备寿命或长期变化的保证. 参数接近边界, 雅可比近乎秩亏或数据不足时, 近似尤其需要审查.

9.3.3 第一组完整程序

程序先保留缺失标记并选出已明确缺失以外的有效数据, 再完成两条拟合路线, 最后计算近似区间. valid 标记非 nan 的响应; 其他非有限输入单独检查, 不把所有异常值静默过滤掉.

Python 在 absolute_sigma=False 且没有提供已知观测标准差时, curve_fit 返回的协方差已经按残差方差缩放[1]. gradient @ covariance @ gradient 之后不要再乘一次 \(s_e^2\). MATLAB 则由解析雅可比自行计算并缩放一次协方差. 两者对应同一局部近似, 求解算法不同.

9.4.2 系数顺序不同, 曲线应当相同

np.polyfit(t,distance,2) 与 MATLAB 的 polyfit 均按降幂顺序返回 \((c,b,a)\)[3]. 设计矩阵方法按列顺序 \((1,t,t^2)\) 返回 \((a,b,c)\). 程序反转多项式系数顺序后核对, 避免把同一个结果误读为两个不同模型.

在 \(t=0.25\) 秒处, 点预测为 56.186228 cm, 95% 逐点均值置信区间为 \([56.155327,56.217129]\), 新观测预测区间为 \([56.103492,56.268963]\). 这些精确线性模型区间以经典正态, 独立同方差误差条件为基础; 不能因为观测按时间排列就自动假定误差独立.

\[ \widehat y=\beta_0+\beta_1x_1+\beta_2x_2+\beta_{11}x_1^2+\beta_{22}x_2^2. \]

9.5.2 三种区间, 三种覆盖对象

前两类区间已经在前面各章出现. 第三类针对一组位置的均值函数, 不是针对某条新的需求观测. 设参数数目为 \(q\), 残差自由度为 \(\nu\), 在逐点均值标准误差上, 将 \(t_{1-\alpha/2,\nu}\) 替换为

\[ \sqrt{qF_{1-\alpha;q,\nu}} \]

可由系数置信椭球得到 Scheffé 同时均值带. 本例 \(q=5,\nu=5\), 乘数为 \(\sqrt{5F_{0.95;5,5}}\). 即使该带在某点比新观测区间更宽, 也不能据此把两者当成同一对象. 这里的同时带公式用于参数线性模型, 不能不加分析地视为一般非线性模型的精确同时区间.

9.5.4 不只看一次项的符号

含平方项时, 收入和价格方向的变化率分别为

\[ \frac{\partial\widehat y}{\partial x_1}=\widehat\beta_1+2\widehat\beta_{11}x_1,\qquad \frac{\partial\widehat y}{\partial x_2}=\widehat\beta_2+2\widehat\beta_{22}x_2. \]

本例收入截面的驻点约为 968.88, 价格截面的驻点约为 7.1911. 因而收入一次项为正, 不表示整个范围都随收入递增. 如果转折与研究背景不相容, 应重新检查模型与数据. 这些是经验拟合形状, 不能自动成为普遍经济规律或因果效应.

9.6 选择路线时, 先核对目标和适用范围

需要判断的问题 对本章案例的含义
是否只变换解释变量 加入 \(t^2\) 后仍拟合原距离尺度
是否变换响应 钢包取对数后改变了误差尺度与目标
参数是否线性进入模型 多项式可直接求解, 指数中的未知参数需迭代
约束是否与求解方式一致 有界求解与参数变换需分别说明边界处理
区间覆盖什么对象 区分参数, 单点均值, 新观测和同时均值带

低次多项式常可作为局部近似, 不必等其他曲线失败后才尝试. 次数过高可能过拟合, 在样本外剧烈变化. 直接非线性模型便于表达特定形状, 但可能局部收敛, 参数上限也可能缺乏数据支持. 两者没有无条件的优劣顺序.

拟合后应检查残差随自变量, 拟合值或采样顺序的变化. 不同尺度的 SSE 不能直接比较大小来评价同一个目标; 即使都在原尺度报告训练误差, 也不能替代适当的留出验证. 观测按时间或使用次序排列时, 验证方案需符合实际预测方向.

动手改变条件

  1. 将钢包线性化后的 \((A,b)\) 直接当作 \((a,b)\) 使用, 会产生什么错误? 解释缺失的首条记录为什么也不能填零后参与对数拟合.
  2. 对钢包原尺度拟合, 预先选用几组可行初值, 比较停止信息, 参数与 SSE. 再计算 \(a=0\) 和 \(b=0\) 两类边界目标. 这些检查能否证明一般问题的全局最优?
  3. 对距离案例分别使用降幂多项式系数和设计矩阵系数, 计算 \(t=0.25\) 秒的预测. 为什么系数顺序不同而曲线相同? 二次系数与加速度的单位怎样换算?
  4. 在需求案例中令 \(u=(x_1-800)/1000,v=x_2-6\), 用 \((1,u,v,u^2,v^2)\) 重新拟合. 核对样本拟合值与指定点预测, 比较设计矩阵条件数. 为什么系数数值可以改变而预测不变?
  5. 设 Logistic 曲线为 \(y=k/(1+a\mathrm e^{-bx})\), 其中 \(a,b,k>0\). 已知上限 \(k=10\) 且观测 \(x=4,y=5\), 计算 \(\ln[(k-y)/y]\). 如果 \(k\) 未知, 为什么不能预先生成确定的变换响应来一次估计全部三个参数?
  6. 三种需求区间分别覆盖什么对象? 为什么不能按宽度把同时均值带叫作新观测预测区间?
