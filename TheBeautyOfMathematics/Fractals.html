第 3 章 简单规则为何能创造复杂世界? — 分形的秘密

一条直线并不复杂. 把中间一小段换成一个折角, 也不困难. 如果对每条新线段继续这样做, 会画出什么?

本章从画线开始. 我们先让画笔前进, 转弯, 再把重复的动作整理成程序, 画出科赫曲线和雪花. 接着观察谢尔宾斯基三角形. 最后, 不再移动画笔, 而是反复计算一个数, 看看怎样由此生成 Mandelbrot 集的图像.

这些图案看起来各不相同, 却有一条共同线索: 每一步的规则很简单, 重复以后, 整体会出现丰富的结构.

3.1 先画一条线, 再添一个折角

3.1.1 让画笔向前走

Python 的 turtle 可以把绘图过程显示在窗口里. 可以把它想成一支会移动的画笔: 笔尖向前走, 就会留下一条线; 改变朝向后再前进, 就会画出折线.

先运行下面的完整程序. 画笔起初朝向右方, 从窗口左侧向右画一条长为 300 个屏幕单位的线段. 屏幕单位用于控制图像大小, 与后面公式中的长度单位可以按比例换算.

penup() 抬起画笔, 移动时不画线; goto(-150, 0) 把画笔移到起点; pendown() 放下画笔; forward(300) 向前画线. turtle.done() 让窗口保持打开. 每段完整程序分别运行, 观察完后关闭窗口, 再进行下一次实验.

我们把这条尚未替换的线段叫作第 0 级.

3.1.2 把中间一段换成两条斜线

将长为 300 的线段分成三等份, 每份长为 100. 保留左右两份, 把中间一份换成一个向上的等边三角形的两条边. 绘制顺序是:

  1. 向右画 100.
  2. 向左转 \(60^\circ\), 再画 100.
  3. 向右转 \(120^\circ\), 再画 100.
  4. 向左转 \(60^\circ\), 最后画 100.

这里的左右转是相对于画笔当前朝向而言. 第三步要转 \(120^\circ\), 因为画笔需要从斜向上改为斜向下; 它不是三角形的内角.

这就得到第 1 级. 画笔仍然停在原线段的右端, 朝向也与开始时相同, 但中间绕过了一个折角.

可以先数一数: 原来只有一段, 现在有几段? 每段多长? 四段加起来是 \(4\times100=400\), 比原来的 300 长了.

3.1.3 先把重复动作缩成一个小循环

上面的四次前进长度相同, 区别只是前进之后的转角. 因此, 完整程序也可以写成下面这样.

angle 依次取列表中的四个数. left(-120) 与 right(120) 含义相同, 最后转 0 度就是不转向. 这段程序与前一段画出相同图形. 循环只减少重复书写, 没有改变构造规则.

3.2 再做一次, 为什么会想到递归

3.2.1 用小折角替换刚才的每一段

第 1 级有四段长为 100 的线段. 对每一段再次实施同样的替换, 每段就变成四段长为 \(100/3\) 的小线段. 这一步得到第 2 级.

注意, 新折角不是一律朝屏幕上方. 应从当前线段的方向出发, 依次转过同样的角度. 画笔的朝向会帮我们完成这件事.

下面的外层循环沿着四个大段安排方向, 内层循环在每个大段的位置画一个小折角.

内层四次转角的和为 \(60-120+60+0=0\). 因此一个小折角画完后, 朝向恢复原样, 外层再决定下一个大段的朝向. 本级共有 \(4\times4=16\) 条小线段.

图 3-1 科赫曲线的第 0 至第 5 级近似. 各图采用相同坐标尺度, 初始线段长度取为 1. 图中的 \(L\) 是对全部小线段实际求和得到的长度.

3.2.2 不再增加一层层循环

继续画第 3 级, 可以再增加一层循环. 可是要画第 4 级, 第 5 级呢? 与其不断增加循环层数, 不如给重复任务起一个名字:

koch(length, level) 表示画一条总跨度为 length, 替换 level 次的科赫曲线.

这里的 length 是被替换直线的长度, 不是最终折线的总长度. 要完成这个任务, 只需区分两种情况:

  • level 为 0: 不再替换, 直接向前画线.
  • level 大于 0: 画四条长度参数为 length/3, 级数为 level-1 的小科赫曲线, 中间按原规则转向.

把同一个任务交给较小的自己, 就是这里的递归. 不必先记住这个术语, 先看程序怎样对应这两种情况.

先把调用中的最后一个数改为 0. 程序直接画长为 300 的线段. 改为 1 时, 四次小任务都在第 0 级停下, 正好画出第 1 级. 改为 2 时, 每个小任务再分成四个更小的任务, 就回到刚才的第 2 级.

return 表示当前调用结束. 每次深入调用, level 都减一; 到 0 时停止继续拆分, 所以不会无限调用. 本章调用时, level 取非负整数.

3.2.3 画出来以后, 再算有多长

先只看前几级:

级数 小线段数量 每段长度 总长度
0 1 1 1
1 4 \(1/3\) \(4/3\)
2 16 \(1/9\) \(16/9\)
3 64 \(1/27\) \(64/27\)

每做一轮, 数量乘以 4, 每段长度除以 3. 因而初始长度为 1 时, 第 \(n\) 级满足

\[ N_n=4^n,\qquad s_n=\frac1{3^n},\qquad L_n=\left(\frac43\right)^n. \]

小线段虽然越来越短, 总长度却越来越大. 第 5 级有 1024 段, 总长度约为 4.213992. 如果初始线段长为 300, 再把这些长度乘以 300 即可.

重复无穷次得到的理想极限叫作科赫曲线. 它具有无限长度. 计算机画出的任意一级只有有限条线段, 总长度仍然有限. 图形看起来已经很细密, 不表示计算机完成了无限次构造.

3.3 把三条曲线围起来, 画成雪花

3.3.1 一条曲线与一圈边界

刚才画的是一条开放曲线. 现在先想象一个正三角形: 沿第一条边画科赫曲线, 向右转 \(120^\circ\), 再画第二条, 然后画第三条. 三条连接起来, 就得到科赫雪花的闭合边界.

下面仍然使用同一个 koch 函数. 真正增加的只是最后的三次重复与转向.

for _ in range(3) 表示重复三次, 不需要使用每次的序号. begin_fill() 与 end_fill() 为闭合区域填色. 顺时针绕三角形前进时, 曲线向行进方向左侧凸起, 正好是三角形外侧. 改变绕行方向时, 也要相应改变凸起方向.

图 3-2 科赫雪花的第 0, 1, 4 级近似. 三图使用相同尺度, \(P\) 表示边界周长, \(A/A_0\) 表示面积与初始面积之比. 这是数学构造, 不代表真实雪花的生长过程.

科赫曲线与科赫雪花相关, 但不应混用名称: 前者从一条线段开始, 后者由三条这样的曲线围成闭合边界.

3.3.2 周长一直增加, 面积会不会也无限增加

初始正三角形边长为 1, 周长为 3, 面积记为

\[ A_0=\frac{\sqrt3}{4}. \]

每条边都按同样规则变长, 所以雪花第 \(n\) 级的周长是

\[ P_n=3\left(\frac43\right)^n. \]

面积怎样变化呢? 先不急着写通式, 看前两轮添了什么.

第一轮添上 3 个小等边三角形. 每个边长是原来的 \(1/3\), 面积就是原来的 \(1/9\). 所以这一轮增加 \(3A_0/9=A_0/3\).

第二轮添上 12 个更小的三角形. 每个边长是原来的 \(1/9\), 面积就是原来的 \(1/81\). 所以这一轮增加 \(12A_0/81=4A_0/27\).

比较这两次新增面积:

\[ \frac{4A_0/27}{A_0/3}=\frac49. \]

往后每一轮也是如此: 添上的三角形数量变为 4 倍, 单个面积变为 \(1/9\), 所以这一轮新增面积只是上一轮的 \(4/9\).

完成到哪一轮 本轮新增面积 累计面积与 \(A_0\) 的比
0 尚未新增 1.000000
1 \(A_0/3\) 1.333333
2 \(4A_0/27\) 1.481481
3 \(16A_0/243\) 1.547325

虽然边界越来越长, 每次添上的面积却越来越少. 这些面积形成等比数列, 累加以后不会超过 \(8A_0/5\). 因此, 理想的科赫雪花有无限长的边界, 所围面积却有有限极限.

选读: 把累计面积写成公式. 第 \(k\) 轮添上 \(3\cdot4^{k-1}\) 个边长为 \(3^{-k}\) 的三角形. 新增三角形内部互不重叠, 因而

\[ \begin{aligned} A_n&=A_0+\frac{A_0}{3}\sum\limits_{k=1}^{n}\left(\frac49\right)^{k-1}\\ &=A_0\left[\frac85-\frac35\left(\frac49\right)^n\right]. \end{aligned} \]

当 \(n\to\infty\) 时, \(A_n\to8A_0/5=2\sqrt3/5\approx0.692820\). 不熟悉等比数列求和时, 可以先用表格理解: 每轮只增加上一轮新增面积的 \(4/9\), 所以总面积的增加会越来越慢.

3.4 不断去掉一块, 最后还剩什么

3.4.1 从一个三角形变成三个小三角形

科赫雪花是在添三角形. 换一种做法: 从一个实心正三角形出发, 连起三条边的中点, 它就被分成四个相同的小三角形. 去掉中间一个, 只留下三个角上的小三角形.

再对留下的每个三角形重复同样的动作. 继续下去, 就得到谢尔宾斯基三角形的逐级近似.

图 3-3 谢尔宾斯基三角形的第 0, 2, 5 级近似. 绿色为保留部分, 白色为去掉部分, \(A_0\) 为初始三角形面积.

程序可以换一种等价画法: 不真的擦掉中间一块, 而是只画三个角上的小三角形. 每个小三角形再交给同一个函数处理, 级数为 0 时才填色.

a, b, c 分别存放一个顶点的两个坐标, 如 a[0] 是横坐标, a[1] 是纵坐标. 两个端点坐标分别取平均, 就得到中点. 三个递归调用对应三个保留的小三角形; 没有调用中间那一块, 它自然就留白.

3.4.2 小块越来越多, 总面积却越来越少

第一次保留初始面积的 \(3/4\). 第二次, 在每个保留部分中再保留 \(3/4\), 所以剩余比例是 \((3/4)^2=9/16\). 第 \(n\) 级剩余面积为

\[ A_n=A_0\left(\frac34\right)^n. \]

与此同时, 保留的小三角形数为 \(3^n\), 每个的边长为原来的 \(2^{-n}\). 数量增加, 并不保证总面积增加, 还要看每一块缩小了多少.

一直重复时, 剩余面积趋于 0. 但这不表示一个点也不剩: 最初的三个顶点始终保留. 面积为零与集合为空, 是不同的事情.

比较这两个实验: 科赫雪花向外添加, 面积逐渐增加到有限值; 谢尔宾斯基三角形向内挖去, 面积逐渐趋于零. 都是重复简单规则, 改变的量却不同.

3.5 换一种重复: 从几个数开始认识 Mandelbrot 集

3.5.1 一个数, 平方后再加回固定参数

前面反复处理的是线段和三角形. 现在给定一个数 \(c\), 从 0 开始, 每次把当前数平方, 再加上 \(c\). 对同一条计算过程, \(c\) 始终不变.

先取 \(c=1\):

\[ 0\longrightarrow1\longrightarrow2\longrightarrow5\longrightarrow26\longrightarrow\cdots. \]

例如, 2 的下一步是 \(2^2+1=5\). 再取 \(c=-1\):

\[ 0\longrightarrow-1\longrightarrow0\longrightarrow-1\longrightarrow0\longrightarrow\cdots. \]

一条越来越大, 一条在两个数之间来回. 规则没有改变, 只是参数不同, 结果就很不一样. 这一串依次产生的数叫作轨道.

参数 \(c\) 从 0 开始的前几项 观察
0 \(0,0,0,0,\ldots\) 一直不变
\(-1\) \(0,-1,0,-1,\ldots\) 来回重复
\(-2\) \(0,-2,2,2,\ldots\) 后来保持为 2
1 \(0,1,2,5,26,\ldots\) 越来越大

图 3-4 四个实参数的前四步轨道. 图中虚线标出 \(-2\) 与 2, 取值等于 2 并不等于已经逃逸.

3.5.2 把参数从一条数轴扩展到一个平面

如果只用实数, 参数都在数轴上. 为了给平面上的每个位置安排一个参数, 可以使用复数.

复数 \(c=a+b\mathrm{i}\) 中, \(a\) 是实部, \(b\) 是虚部, \(\mathrm{i}^2=-1\). 我们用横坐标表示 \(a\), 纵坐标表示 \(b\). 例如 \(-1+0.5\mathrm{i}\) 就对应点 \((-1,0.5)^{\mathsf T}\).

Python 把虚数单位写作 1j. 下面先不画整张图, 只计算一个参数的前六步.

c 是选定的位置, 始终不变; z 是不断更新的轨道值. 每次 z * z + c 算完, 新值接替旧值. 不要把两者混淆: 最终图片中标记的位置是参数 c, 不是把某一条轨道逐点画在平面上.

用数学记号整理这个规则, 就是

\[ z_0=0,\qquad z_{n+1}=z_n^2+c. \]

Mandelbrot 集收集的是使这条轨道始终有界的所有复数参数 \(c\). 有界可以理解为: 整条轨道始终待在某个有限大小的圆里, 不会越跑越远. 它可以重复或变化, 不要求最终停在一个点.

3.5.3 怎样知道一个参数已经跑远

对于这里从 0 开始的规则, 只要某一步满足 \(|z|>2\), 就能判定轨道将趋向无穷, 对应参数不属于 Mandelbrot 集[2]. \(|z|\) 表示复数对应点到原点的距离, Python 用 abs(z) 计算.

这里是严格大于 2. 表中的 \(c=-2\) 会产生 \(-2,2,2,\ldots\), 却没有跑向无穷. 把条件误写成大于或等于 2, 就会误判它.

下面写一个小函数. 它返回第一次跑出半径为 2 的圆时的步数; 如果在规定次数内还没有跑出去, 返回 0.

输出依次为 0, 0, 0, 3. 参数 1 在第三步得到 5, 所以返回 3; 其他三个参数没有被检测到逃逸.

算了 300 次还没跑远, 只能说明前 300 次没有跑远. 第 301 次以后会怎样, 仍需进一步判断. 因此, 返回 0 的含义是本次未检测到逃逸, 不是程序已经证明它永远不会逃逸. 对刚才几个简单参数, 我们另有手算的周期或恒定关系, 才能确认它们有界.

3.6 从一个点到一张图

3.6.1 每一列确定横坐标, 每一行确定纵坐标

画一张图, 就要对许多参数重复刚才的检查. 可以把观察窗口分成很多小格, 每个小格选中心点作代表, 检查这个点对应的参数.

先看一个很小的例子. 把横向范围 \([-2,2]\) 分成四列, 中心横坐标依次为 \(-1.5,-0.5,0.5,1.5\). 把纵向范围 \([-1.5,1.5]\) 分成三行, 从上到下的中心纵坐标为 \(1,0,-1\). 这样得到12个参数:

第0列 第1列 第2列 第3列
第0行 \(-1.5+\mathrm{i}\) \(-0.5+\mathrm{i}\) \(0.5+\mathrm{i}\) \(1.5+\mathrm{i}\)
第1行 \(-1.5\) \(-0.5\) \(0.5\) \(1.5\)
第2行 \(-1.5-\mathrm{i}\) \(-0.5-\mathrm{i}\) \(0.5-\mathrm{i}\) \(1.5-\mathrm{i}\)

先选行, 就知道虚部; 再选列, 就知道实部. 两者组合, 就能调用 escape_steps.

3.6.2 用两层循环逐点计算

下面是生成完整图像的独立程序. 第一部分仍是刚才的单点函数; 第二部分逐行, 逐列确定参数并记录结果; 最后才把结果显示成颜色.

先看参数怎样产生. (xmax-xmin)/width 是每一列的宽度, col+0.5 把位置移到小格中心. 纵坐标也取格子中心, 但从 ymax 开始往下减, 因为图像的第0行在顶部. complex(x, y) 组成复数 \(x+y\mathrm{i}\).

再看结果怎样保存. result 是一张有 height 行, width 列的表. result[row, col] 对应一个小格, 存放首次逃逸步数或表示本次未检测到逃逸的0. 每次都由 escape_steps 内部的 z=0j 重新开始, 不沿用上一个参数的轨道.

最后看颜色. np.ma.masked_equal(result, 0) 把所有0位置标记出来, set_bad("black") 让这些位置显示为黑色. 其他位置按首次逃逸步数着色. 颜色是帮助观察的显示规则, 不是复数参数本身的颜色, 也不改变集合的定义.

extent 把图像放回对应的坐标窗口; origin="upper" 让第0行显示在上方; aspect="equal" 让横纵坐标的一单位显示为相同长度. 这些设置负责图像怎样摆放, 不参与轨道计算.

3.6.3 先看全图, 再看局部

图 3-5 Mandelbrot 集的全图与局部数值近似. 左图窗口为 \([-2.1,0.8]\times[-1.16,1.16]\), 白框标出右图窗口 \([-0.82,-0.70]\times[0.04,0.16]\). 两图最多迭代300次, 分别使用 \(900\times720\) 与 \(700\times700\) 个采样点. 黑色表示本次未检测到逃逸, 彩色区域表示已检测到逃逸.

正文程序先用较少采样点完成同一任务. 如果想观察右侧局部, 把横向范围改为 -0.82, -0.70, 纵向范围改为 0.04, 0.16, 再把宽, 高都设为400, 重新运行即可.

这与放大旧图片不同. 放大图片只会放大已有像素; 缩小窗口后重新计算, 会在那一小块区域安排新的采样点, 才有机会看到新的细节. 两层循环的写法便于理解, 增大图像和迭代预算时计算也会更慢.

3.7 从图形中读出规律

3.7.1 小块为什么会像整体

回看科赫曲线. 整体由四条缩小为原来 \(1/3\) 的同类曲线接成, 小曲线需要转向, 但构造规则相同. 谢尔宾斯基三角形则由三个缩小为原来 \(1/2\) 的自身副本组成. 这种整体与缩小副本之间的对应关系, 叫作自相似.

Mandelbrot 图的局部也会出现相似形态, 但不能因此认定它与前两个例子有完全相同的固定缩放结构. 看起来相似, 与能够按同一个比例精确拼回整体, 不是同一要求.

自然界中的叶片, 云团, 海岸轮廓也可能在一定尺度范围内显示类似特征, 但真实物体存在观察尺度与物理限制, 不应直接当作无限重复的理想图形.

3.7.2 多算一些, 能知道更多吗

图 3-6 同一局部窗口, 同一 \(650\times650\) 网格下的预算比较. 左图最多迭代30次, 右图最多迭代300次. 图题给出尚未检测到逃逸的点数. 两幅图各自按预算映射颜色, 不宜直接按颜色比较步数; 应重点比较黑色区域.

右图中的部分原黑色位置变成彩色: 它们前30次没有跑远, 后来却逃逸了. 对同一参数, 已经查到首次逃逸步数后, 继续增加预算不应改变这一首次步数. 不过, 剩余黑色点仍然只是本次未检测到逃逸.

增加像素数与增加迭代次数也不同. 前者多看一些位置, 后者在同一位置多看一些步骤. 不能靠一种设置代替另一种.

3.7.3 选读: 为什么维数可以不是整数

把一条线段缩成原来的 \(1/2\), 需要2份才能拼回原线段. 把正方形的边长缩成原来的 \(1/2\), 则需要4份才能拼回原正方形. 数量关系分别是 \(2=2^1\), \(4=2^2\).

对科赫曲线, 尺度缩为 \(1/3\) 后需要4份. 如果也用一个指数描述数量与尺度, 就要让 \(3^D=4\), 因而

\[ D=\frac{\log4}{\log3}\approx1.261860. \]

对谢尔宾斯基三角形, 对应关系是 \(2^D=3\), 所以

\[ D=\frac{\log3}{\log2}\approx1.584963. \]

这里的 \(D\) 叫作相似维数, 描述这些标准构造的副本数量与缩放比例[1]. 它不表示一个点要用1.26个坐标表示. 也不能对任意图片数出几个看起来相似的部分, 就直接套用公式; 比例, 数量和重叠方式都需要检查. 暂时不研究维数, 也不影响前面的画图与计算.

3.8 动手改变条件

  1. 将科赫递归调用的级数依次改为0, 1, 2, 3. 先预测最底层前进次数, 再观察结果.
  2. 把初始长度从300改为600. 总长度和雪花面积分别变为原来的多少倍? 为什么二者不是同一个倍数?
  3. 将科赫程序的三个转角改为 \(-60^\circ,120^\circ,-60^\circ\). 图形怎样变化? 总长度是否变化?
  4. 将正 \(60^\circ\) 的旋转改为 \(45^\circ\), 并用 \(-90^\circ,45^\circ\) 接回朝向. 此时四段若仍等长, 终点是否还在原来的位置? 原替换规则的跨度和长度公式能否照搬?
  5. 对谢尔宾斯基构造, 用逐次乘以 \(3/4\) 的方法, 找出第一次使剩余面积小于初始面积十分之一的级数.
  6. 手算参数 \(c=\mathrm{i}\) 的轨道. 提示: \(\mathrm{i}^2=-1\). 它会逃逸吗? 再用程序核对.
  7. 分别用30次与300次预算检查同一个小网格. 统计未检测到逃逸的点数, 说明结果为什么可能不同.
  8. 不改变窗口, 把图像宽, 高各增大一倍. 总采样点数增加多少倍? 这能否代替增加迭代预算?
  9. 在图 3-5 中挑选一个区域, 比较直接放大旧图片与缩小窗口重新计算的效果.

本章的三个构造都使用确定性规则: 条件给定后, 每一步的结果也就确定了. 下一章将允许单次结果随机变化, 继续观察多次重复以后, 整体是否仍有可以描述的规律.
