非线性规划：从模型建立到结果判断

学习目标：识别决策变量中的非线性关系，正确编写目标与约束，使用 Python 或 MATLAB 求解，并区分可行方案、驻点、局部最优和全局最优。

阅读路线：第一至四节介绍原理与二次函数例题；第五节从固定料场运输过渡到选址；第六节利用本例的特殊结构核验全局结果，属于选读内容。

一、非线性规划从哪里来

1.1 变量进入距离、比例与曲线关系

在线性规划中，每增加一个单位的活动或产品，效益与资源消耗按固定比例变化。实际问题还可能包含平方、乘积、平方根、三角函数或其他非线性关系。

例如，料场的位置已知时，到工点的距离是常数；位置需要决定时，距离变为：

\[ \sqrt{(u-a)^2+(v-b)^2}, \]

其中 \((u,v)\) 是待确定的料场坐标，\((a,b)\) 是已知工点坐标。距离于是成为关于决策变量的非线性函数。

场景 决策变量 可能出现的非线性关系
公共设施选址 设施位置与分配量 距离、分配量与距离的乘积
工程设计 尺寸、角度、控制参数 平方项、三角函数、性能响应曲线
资源效率优化 资源投入量 收益递减、比值、饱和关系
运动与避障 位置、姿态或轨迹参数 距离、安全区域、角度关系
参数拟合 模型参数 非线性模型的残差平方和

非线性要相对于决策变量判断。公式中有平方根，并不自动说明问题是非线性规划；如果平方根里的坐标全部已知，算出的距离仍是一个常数系数。

同理，“增长率”“收益率”等名称本身不决定模型类型，必须看它们与待求变量的具体函数关系。

1.2 定义与建模三要素

非线性规划（Nonlinear Programming，简称 NLP）研究的是：目标函数或约束函数中至少一个对决策变量非线性的最优化问题。

建模仍然围绕三要素展开：决策变量、目标函数、约束条件。例如：

\[ \begin{aligned} &\max\quad F(x_1,x_2)=x_1^2+x_2^2-x_1x_2-2x_1-5x_2,\\ &\text{s.t.}\quad\begin{cases} x_2-(x_1-1)^2\geqslant0,\\ 2x_1-3x_2+6\geqslant0. \end{cases} \end{aligned} \]

目标中有二次项与变量乘积，第一条约束也是非线性的，因而这是 NLP。第四节会完整求解它，并讨论为什么“求最大”与“求最小”不能混用。

常见非线性表达式包括：

\[ x^2,\quad x_1x_2,\quad \mathrm{e}^{x},\quad \frac1x,\quad\sin x,\quad\log_2x. \]

出现 \(1/x\) 或 \(\log x\) 时，还必须明确函数定义域；出现距离函数时，还要考虑距离为 0 处的可微性。

1.3 与线性规划的联系和区别

比较项目 线性规划 非线性规划
目标与约束 目标线性，约束为线性等式、不等式及边界 至少一项关系非线性
最优位置 对非空有界多面体，至少有一个顶点最优解；也可有整条边或更多点最优 可在内部或边界取得最优值
初始值 一般使用 linprog 时不需自行给初值 局部求解器通常需要初值
全局判断 结构清晰，可由成熟 LP 方法确认全局最优 要结合凸性、下界、结构或全局方法判断
数值结果 浮点实现仍需检查容差 同样需要检查容差，还需分析局部性

线性规划也可能有内部最优点。例如，在 \(0\leqslant x\leqslant1\) 上最小化常数 0，每个可行点都是最优解，包括内部点。

非线性也不等于非凸。有些非线性问题具有凸结构，可以确认全局最优；有些则存在多个局部最优，需要更加谨慎。

二、局部最优、凸性与一阶条件

2.1 可行解、驻点与最优解

设可行域为 \(\mathcal F\)，考虑最小化问题。

  • 可行解：满足所有约束的点。
  • 局部最优解：在该点附近的可行方案中，目标值不比它更小。
  • 全局最优解：在整个可行域中，目标值不比它更小。
  • 驻点：无约束可微情形下梯度为 0 的点；约束情形还需考虑拉格朗日条件与可行方向。

对于无约束最小化 \(f(x)=x^2\)，\(x=0\) 是内部的全局最优解。对于 \(f(x)=-x^2\)，\(x=0\) 同样满足导数为 0，却是最大点。一阶变化为 0，并不能独立证明最小值。

局部数值算法可能返回一个满足其停止标准的点；它甚至可能仅是驻点，或者因步长过小而停下。因此，success=True 或正的终止标志不能替代最优性论证。

2.2 初值为何重要

局部算法从初始点出发，利用局部函数信息逐步更新。如果目标有多个“低谷”，不同初值可能进入不同区域，得到不同候选解。

多初值计算、改变算法、先随机搜索再局部改进，都可以帮助找到更好的候选解。但这几种操作本身不构成全局最优保证。在非凸问题中，应报告“搜索到的最好可行值”，除非还有全局证据。

对于确定性模型、固定初值、相同算法和环境，计算通常可复现。使用随机初值时，还应记录随机种子和生成方式；结果的差异可能来自初值、算法、数值精度或软件版本。

2.3 怎样判断凸结构

如果任意两个可行点之间的整条线段仍在可行域内，这个可行域就是凸的。对最小化问题，一个常用的充分结构是：

  1. 目标函数为凸函数。
  2. 写成 \(c_i(x)\leqslant0\) 的不等式函数为凸函数。
  3. 等式约束为仿射等式，并有适当的变量边界。

在这种凸优化问题中，局部最优也是全局最优；若目标严格凸，最优解至多一个。最大化问题的对应条件是最大化凹函数，而不是最大化凸函数。

梯度是各一阶偏导数组成的向量，用于描述函数在各坐标方向的局部变化。对定义在凸开集上的二阶连续可微函数，可以检查由二阶偏导数组成的 Hessian 矩阵：它处处半正定时，函数为凸函数；处处正定时，函数严格凸。初学者可先从“可行点连线仍可行”的几何图像理解凸集合，再结合二次函数学习凸性。

2.4 KKT 条件：选读

卡鲁什—库恩—塔克条件（Karush–Kuhn–Tucker，简称 KKT）把梯度、约束和乘子联系起来。对可微问题：

\[ \begin{aligned} &\min_x\quad f(x),\\ &\text{s.t.}\quad\begin{cases} c_i(x)\leqslant0,&i=1,\ldots,m,\\ h_j(x)=0,&j=1,\ldots,p. \end{cases} \end{aligned} \]

定义拉格朗日函数：

\[ L(x,\lambda,\nu)=f(x) +\sum\limits_i\lambda_ic_i(x) +\sum\limits_j\nu_jh_j(x). \]

KKT 条件包括：

\[ \begin{cases} \nabla_xL(x,\lambda,\nu)=0,\\ c_i(x)\leqslant0,\qquad h_j(x)=0,\\ \lambda_i\geqslant0,\\ \lambda_ic_i(x)=0. \end{cases} \]

最后一条称为互补松弛：若某个不等式在该点严格满足，即 \(c_i(x)<0\)，其对应乘子为 0。在适当的约束资格条件下，局部最优点满足 KKT 必要条件；在上述凸结构下，满足 KKT 的点可据此证明全局最优。对一般非凸问题，KKT 条件通常只是必要条件。

三、统一模型与求解器接口

3.1 统一数学形式

本章主要使用最小化形式：

\[ \begin{aligned} &\min_x\quad f(x),\\ &\text{s.t.}\quad\begin{cases} Ax\leqslant b,\\ A_{\mathrm{eq}}x=b_{\mathrm{eq}},\\ c(x)\leqslant0,\\ h(x)=0,\\ l\leqslant x\leqslant u. \end{cases} \end{aligned} \]

最大化 \(F(x)\) 时，将求解器目标设为 \(f(x)=-F(x)\)，最终用 \(F(x)=-f(x)\) 还原。每次比较结果时，都要确认是在比较求解器的最小值，还是原目标的最大值。

变量不一定非负。位置坐标、偏差和抽象变量可取负值；质量和运输量则应非负。没有题意依据时，不能为了“方便”自行增加 \(x\geqslant0\)。

3.4 怎样选择方法

先识别问题结构，再选择算法。对本章的光滑约束问题，Python 使用 SLSQP，MATLAB 使用 SQP，并在二次函数例题中与内点法对照。

问题结构 可以优先了解的方法 需要注意的条件
无约束、可微 BFGS、共轭梯度法 关注梯度精度与局部性
只有变量边界、可微 L-BFGS-B 边界应符合变量含义
光滑等式与不等式约束 SLSQP、trust-constr 核对约束方向与可行性
不可微或存在离散决策 专门的非光滑、离散优化方法 先分析是否能利用等价模型或特殊结构

SciPy 的 minimize 未指定方法时，会根据约束与边界选择方法；显式指定 method 可以使程序的求解意图更清楚。MATLAB 的 fmincon 也提供多种算法，各有适用条件，不能仅根据一次运行的结果判断某种算法普遍更优。

3.5 返回值与容差

Python 中先检查 result.success、result.message，再读取 x、fun；status 和 nit 可帮助判断终止原因与迭代情况。梯度、Hessian 近似、乘子及各种调用次数是否返回，取决于方法与版本，不能假设所有字段始终存在。

MATLAB 中检查 exitflag 与 output.message，并查看约束违反量和一阶信息。步长、目标变化、可行性与最优性容差对应不同停止条件；把容差设得很小，并不能自动获得同样位数的正确解。

求解器通常接受非严格约束。\(g(x)>0\) 不应直接当成 \(g(x)\geqslant0\) 的同义表达；若业务要求严格留有余量，可设置明确的安全间隔，但要说明这会改变原问题。

四、例题一：统一最大化与最小化方向

4.1 同一个函数，两种优化方向

考虑以下最大化问题：

\[ \begin{aligned} &\max\quad F(x_1,x_2)=x_1^2+x_2^2-x_1x_2-2x_1-5x_2,\\ &\text{s.t.}\quad\begin{cases} x_2-(x_1-1)^2\geqslant0,\\ 2x_1-3x_2+6\geqslant0. \end{cases} \end{aligned} \]

同一可行域上，最小化 \(F\) 与最大化 \(F\) 是两个不同的问题。前者寻找最低处，后者寻找最高处。为了看清求解器中的目标方向，本节同时求解这两个问题，但始终用 \(F\) 表示原函数。

图 1 展示可行域、函数等值线及主要候选点。

图 1　抛物线与直线之间的可行域。\((1,0)\) 是全局最大点，\((3,4)\) 是全局最小点；左侧交点还构成一个局部最大点。

4.2 可行域

约束等价于：

\[ (x_1-1)^2\leqslant x_2\leqslant\frac{2x_1+6}{3}. \]

下界不超过上界，要求：

\[ 3(x_1-1)^2\leqslant2x_1+6 \quad\Longleftrightarrow\quad 3x_1^2-8x_1-3\leqslant0. \]

因此：

\[ -\frac13\leqslant x_1\leqslant3, \qquad0\leqslant x_2\leqslant4. \]

实际可行域是抛物线与直线之间的闭区域，而不是整个包围矩形。这里 \(x_1\) 可以为负，不能自行增加 \(x_1\geqslant0\)。

转换为 MATLAB 约束时：

\[ A=\begin{pmatrix}-2&3\end{pmatrix},\quad b=6, \qquad c(x)=(x_1-1)^2-x_2\leqslant0. \]

Python 的 SLSQP 字典接口则使用：

\[ g_1(x)=x_2-(x_1-1)^2\geqslant0, \qquad g_2(x)=2x_1-3x_2+6\geqslant0. \]

4.3 Python 入门代码：把两个方向分开求

运行结果为：最大化得到 \((1,0)\)，\(F=-1\)；最小化得到 \((3,4)\)，\(F=-13\)。求解器计算结果还需要下一节的数学分析确认。

4.4 最大值为什么是 \(-1\)

固定 \(x_1\) 后，\(F\) 关于 \(x_2\) 是凸二次函数，在允许的闭区间上最大值可在一个端点取得。因此只需比较上、下两条边界。

上边界 \(x_2=(2x_1+6)/3\) 上：

\[ F_{\mathrm{upper}}(x_1)=\frac79x_1^2-\frac{14}{3}x_1-6. \]

这个函数在 \([-1/3,3]\) 上为凸函数，最大值在端点之一取得。

下边界 \(x_2=(x_1-1)^2\) 上：

\[ F_{\mathrm{lower}}(x_1)=x_1^4-5x_1^3+4x_1^2+3x_1-4, \]

\[ F_{\mathrm{lower}}'(x_1) =4x_1^3-15x_1^2+8x_1+3 =(x_1-1)(4x_1+1)(x_1-3). \]

比较端点与导数为 0 的候选点：

候选点 \((x_1,x_2)\) 原目标 \(F\)
\((-1/3,16/9)\) \(-353/81\approx-4.358025\)
\((-1/4,25/16)\) \(-1131/256\approx-4.417969\)
\((1,0)\) \(-1\)
\((3,4)\) \(-13\)

最大值因此为：

\[ F_{\max}=-1,\qquad x^*=(1,0). \]

若求解器最小化 \(-F\)，它在这个点返回的目标值应为 1。将该值取负，才得到原函数的最大值 \(-1\)。

4.5 最小值为什么是 \(-13\)

令 \(u=x_1-3\)、\(v=x_2-4\)，直接整理可得：

\[ F(x_1,x_2) =-13+u^2+v^2-uv =-13+\frac12\bigl[u^2+v^2+(u-v)^2\bigr]. \]

后三项均非负，且只有 \(u=v=0\) 时同时为 0。\((3,4)\) 又满足两条约束，所以它是最小化问题唯一的全局最优解，最小值为 \(-13\)。

从凸性看，\(F\) 的 Hessian 为：

\[ \nabla^2F=\begin{pmatrix}2&-1\\-1&2\end{pmatrix}, \]

特征值为 1、3，故 \(F\) 严格凸。可行域也是凸的，因此最小化 \(F\) 是凸问题，而最大化 \(F\) 一般不具有同样的凸优化保证。

5.2 变量、约束与目标

设第 \(i\) 个工点位置为 \((a_i,b_i)\)，需求为 \(d_i\)；第 \(j\) 个料场位置为 \((u_j,v_j)\)，容量为 \(e_j=20\)；\(q_{ij}\) 表示从料场 \(j\) 向工点 \(i\) 的日运输量。

运输量应满足料场容量与工点需求。两问的共同模型为：

\[ \begin{aligned} &\min\quad T=\sum\limits_{j=1}^{2}\sum\limits_{i=1}^{6} q_{ij}\sqrt{(u_j-a_i)^2+(v_j-b_i)^2},\\ &\text{s.t.}\quad\begin{cases} \sum\limits_{i=1}^{6}q_{ij}\leqslant e_j,&j=1,2,\\ q_{i1}+q_{i2}=d_i,&i=1,\ldots,6,\\ q_{ij}\geqslant0,&i=1,\ldots,6,\quad j=1,2. \end{cases} \end{aligned} \]

第一问中位置已知，只有运输量是变量；第二问中位置也需要决定。

用 \(q_{ij}\) 表示运输量，用 \((u_j,v_j)\) 表示位置，可以清楚地区分两类决策变量。

模型包含两条容量不等式、六条需求等式，以及各运输量的非负限制。

5.3 固定位置为何是线性规划

第一问里 \((u_j,v_j)\) 已知，距离 \(L_{ij}\) 为常数，于是：

\[ \begin{aligned} &\min\quad T=\sum\limits_{j=1}^{2}\sum\limits_{i=1}^{6}L_{ij}q_{ij},\\ &\text{s.t.}\quad\begin{cases} \sum\limits_{i=1}^{6}q_{ij}\leqslant20,&j=1,2,\\ q_{i1}+q_{i2}=d_i,&i=1,\ldots,6,\\ q_{ij}\geqslant0,&i=1,\ldots,6,\quad j=1,2. \end{cases} \end{aligned} \]

目标与约束均对运输量线性，应直接使用 LP 求解。平方根已经用于计算常数系数，不会使这个模型变成 NLP。

采用变量顺序：

\[ q=(q_{11},q_{21},\ldots,q_{61}, q_{12},q_{22},\ldots,q_{62})^{\mathsf T}. \]

前六个是第一个料场的运输量，后六个是第二个料场的运输量。容量矩阵为两个分块的行向量，需求矩阵为：

\[ A_{\mathrm{eq}}=\begin{pmatrix}I_6&I_6\end{pmatrix}. \]

联合目标通常非凸：虽然固定位置时可以优化运输量，固定运输量时也可以分别优化两个位置，但两者同时作为变量，并不能由此推出联合凸性。

\[ [0.5,8.75]\times[0.75,7.75]. \]

理由是：把矩形外的点逐坐标截到矩形上，对每个工点的距离都不会增大。因此至少有一组最优位置在这个矩形内。实际题目若另有可用土地、道路或禁建区域，应重新加入这些条件。

5.6 不可微距离与光滑近似

当料场恰好与某工点重合时，欧氏距离在这个位置不可微。不能把它当成处处光滑的函数而忽略求解器要求。

本节的局部求解用：

\[ \sqrt{(u_j-a_i)^2+(v_j-b_i)^2+\varepsilon^2} \]

近似真实距离，取 \(\varepsilon=10^{-6}\) 千米。对于任何满足需求的非负运输方案：

\[ 0\leqslant T_{\varepsilon}(w)-T(w) \leqslant\varepsilon\sum\limits_{i=1}^{6}d_i =36\varepsilon. \]

因为每条距离的增加量最多为 \(\varepsilon\)。这里 \(36\varepsilon\) 只控制目标的光滑近似误差，不控制非凸局部求解距离全局最优的误差。

最终报告时重新使用真实距离，并在得到的位置上重新求运输 LP，保证展示的供应计划满足平衡约束。

六、选读：本例如何进一步核验全局结果

6.1 为什么多初值之外还需要证据

只做第五节的随机初值和局部求解，能够找到约 85.26604 的可行值，但还不能排除其他未搜索到的位置与运输组合更好。

本例只有两个料场、六个工点，且目标对固定位置下的运输量线性，可以利用这一特殊结构，把全局核验变成有限个凸子问题。这种做法不适用于任意 NLP。

6.2 把 12 个运输量降为 6 个

令 \(s_i=q_{i1}\)，则第二个料场的运输量由需求平衡确定：

\[ q_{i2}=d_i-s_i. \]

可行运输集合于是为：

\[ 0\leqslant s_i\leqslant d_i, \qquad16\leqslant\sum\limits_{i=1}^{6}s_i\leqslant20. \]

下界 16 来自第二个料场容量：\(36-\sum\limits_{i=1}^{6}s_i\leqslant20\)。

这个多面体的顶点可以分成两类：

  1. 六个 \(s_i\) 都等于 0 或对应需求 \(d_i\)，并满足总量限制。
  2. 总量恰好为 16 或 20，至少五个 \(s_i\) 等于各自的边界，剩余一个由总量确定。

如果有两个分量都在各自上下界之间，就能让一个增加一点、另一个减少一点，得到两侧不同的可行点，原点便不是顶点。如果仅有一个分量不在边界，且总量约束也不取等号，那么单独增减这个分量仍可保持可行，原点同样不是顶点。

去重后，本组数据共有 106 个运输顶点，包括互换料场编号得到的对称方案。对于任何固定位置，运输 LP 至少有一个顶点最优解，因此至少有一组联合全局最优方案的运输量来自这 106 个顶点。

6.3 固定运输量后，位置子问题是凸的

给定一个顶点 \(s\)，两料场的位置可以分别求解：

\[ \begin{aligned} &\min_z\quad \sum\limits_{i=1}^{6}w_i\|z-p_i\|_2,\\ &\text{s.t.}\quad\begin{cases} z\in\mathbb R^2. \end{cases} \end{aligned} \]

其中第一个料场的权重为 \(w_i=s_i\)，第二个为 \(w_i=d_i-s_i\)，\(p_i=(a_i,b_i)\)。这叫加权几何中位点问题，距离的非负加权和是凸函数。

若最优位置与工点重合，可以用次梯度判断；若不重合，可使用 Weiszfeld 迭代。这一步没有把距离平方化，求的仍然是原来的“吨数乘距离”。

要检查位置子问题的精度，还可以构造下界。对任意向量 \(r_i\)，只要：

\[ \|r_i\|_2\leqslant w_i, \qquad\sum\limits_i r_i=0, \]

就有：

\[ \sum\limits_i w_i\|z-p_i\|_2 \geqslant\sum\limits_i r_i^{\mathsf T}(z-p_i) =-\sum\limits_i r_i^{\mathsf T}p_i. \]

右端与 \(z\) 无关，是有效下界。可行位置给出上界，二者之差可以检查几何中位点计算的精度。

比较 106 个运输顶点的上、下界，便能给联合问题做全局数值核验。

6.4 上下界给出的数值结论

对 106 个运输顶点分别计算位置子问题的可行值 \(U_k\) 与下界 \(L_k\)。联合问题的全局最优值 \(T^*\) 满足：

\[ \min_k L_k\leqslant T^*\leqslant\min_k U_k. \]

完整枚举得到：

\[ \min_k L_k\approx85.266040872079,\qquad \min_k U_k\approx85.266040872111. \]

两者相差约 \(3.1\times10^{-11}\) 吨千米。因而，将最优运输指标保留六位小数，得到：

\[ T_{\mathrm{new}}\approx85.266041\text{ 吨千米}. \]

以上为普通双精度计算的全局数值核验。上下界的推导在数学上成立，但计算没有采用有向舍入的区间运算；实际报告的精度应与数值误差相匹配。

与固定料场方案相比，每天减少的运输指标为：

\[ \Delta T=T_{\mathrm{old}}-T_{\mathrm{new}} \approx50.961479\text{ 吨千米}, \]

降幅约为 \(37.41\%\)。该比较仅针对运输吨千米指标。模型尚未计入建设、迁移、土地与道路条件，因此不能直接把这一结果解释为实际工程总费用的降幅。

七、结果检查与方法评价

7.1 建模与求解的完整流程

  1. 定义变量、单位、上下界、连续性与整数性。
  2. 写出原目标，明确求最大还是求最小。
  3. 区分线性约束、非线性约束与函数定义域。
  4. 判断凸性、可微性和特殊结构，选择适合的方法。
  5. 构造合理初值，必要时利用 LP 或参数化确保可行。
  6. 求解并读取状态，回代所有约束与原目标。
  7. 对非凸问题使用多初值与其他核验，但按证据强弱说明结果。
  8. 解释实际方案、模型限制与数据敏感性。

7.2 结果应怎样命名

已掌握的证据 适合报告的说法
只检查了约束 可行方案与对应目标值
局部算法成功停止且通过回代 满足数值停止条件的候选解
局部最优条件得到充分核验 局部最优解
多初值中目标最好 本次搜索到的最好可行方案

对最小化问题，任意可行值都是全局最优值的上界；对最大化问题，任意可行值都是全局最优值的下界。若有反方向的界，就能用差距说明质量，而不是仅凭“多跑了几次”判断可靠性。

7.3 误差与尺度

优化结果可能同时受到模型简化、数据误差、光滑近似误差、局部搜索误差和浮点容差的影响。它们不能混为一谈。

例如，第五节的 \(36\varepsilon\) 只约束平滑前后的目标差；多初值寻找的是较好的局部区域；供需残差检查的是数值可行性；第六节的上下界比较才用于进一步核验本例的全局指标。

若不同变量的单位或数量级相差很大，可考虑合理缩放。缩放后应换算回原单位再核算资源、需求与目标值。

7.4 优点与局限

NLP 能表达比例、距离、性能曲线等实际关系，建模灵活；成熟求解器也提供统一的约束接口、梯度和二阶信息支持。

它的局限主要来自非凸性、不可微性与数值条件。局部求解可能依赖初值，随机搜索在高维空间中也可能很低效；严格等式通常占据低维集合，不能指望独立随机撒点轻易满足。

当存在整数决策、固定启用费用或离散候选点时，还需考虑混合整数非线性规划或适当的等价模型。连续 NLP 不能通过简单四舍五入就自动处理这些限制。

8.1 练习

  1. 为什么固定料场的运输模型是 LP，而选址与运输共同决定时一般是 NLP？
  2. 将 \(x_2-(x_1-1)^2\geqslant0\) 分别写成 MATLAB 非线性约束与 Python SLSQP 字典约束。
  3. 对第四节的 \(F\)，如果 Python 直接使用 minimize(F,...)，求的是哪一个问题？它的全局值是多少？
  4. 第五节运输需求总量为 36 吨。令第一个料场供应 \(s_i\)，为什么必须要求 \(16\leqslant\sum\limits_{i=1}^{6}s_i\leqslant20\)？
  5. 将光滑距离参数改为 \(\varepsilon=10^{-4}\) 千米，平滑目标与真实目标的差最多是多少？这能否控制局部解与全局解的差距？
  6. 多个随机初值最终都返回同一个目标值，是否足以证明全局最优？

8.2 参考答案

  1. 固定坐标时，距离已经算成常数，目标对运输量是线性的；未知位置进入距离函数，并与运输量相乘，联合目标通常非线性且非凸。
  2. MATLAB 返回 \(c=(x_1-1)^2-x_2\) 并要求 \(c\leqslant0\)；Python 返回 \(g=x_2-(x_1-1)^2\) 并设置 type='ineq'，要求 \(g\geqslant0\)。
  3. 它直接最小化 \(F\)，而非最大化。全局最小点为 \((3,4)\)，最小值为 \(-13\)。最大化应最小化 \(-F\)，全局最大值为 \(-1\)。
  4. 第一个料场不能超过 20 吨；第二个料场供应 \(36-\sum\limits_{i=1}^{6}s_i\)，也不能超过 20 吨，所以 \(\sum\limits_{i=1}^{6}s_i\geqslant16\)。
  5. 平滑目标与真实目标的差不超过 \(36\times10^{-4}=0.0036\) 吨千米。这个界控制距离平滑误差，不控制非凸局部求解的全局差距。
  6. 不能。可能是初值覆盖不够，也可能多个初值进入同一个局部区域。还需解析比较、凸性、下界或其他适用的全局核验证据。
